# Учебная конфигурация «Оказание услуг»

Учебный проект на 1С:Предприятие 8.3,
созданный по мотивам пособия Радченко и Хрусталевой.

## Реализовано

- справочник «Номенклатура»;
- документ «Оказание услуги»;
- табличная часть документа;
- расчет цены и суммы;
- печатная форма;
- проведение по нескольким регистрам;
- регистр бухгалтерии;
- субконто;
- общие модули.

## Самостоятельные доработки



## Версия

1С:Предприятие 8.3

## Ограничения

Проект является учебным и не предназначен
для использования в реальном бухгалтерском учете.
