# Учебная конфигурация «Оказание услуг»

Учебный проект на 1С:Предприятие 8.3,
созданный по мотивам пособия Радченко и Хрусталевой.

## Назначение проекта

Конфигурация предназначена для оформления оказания услуг клиентам,
расчета стоимости услуг, формирования печатных документов и отражения
операций в регистрах учета.

## Реализованные возможности

- ведение списка номенклатуры;
- оформление документа «Оказание услуги»;
- добавление услуг в табличную часть документа;
- автоматическое заполнение цены;
- расчет суммы по строке;
- расчет общей суммы документа;
- проведение документа;
- формирование движений по нескольким регистрам;
- использование регистра накопления;
- использование регистра бухгалтерии;
- применение субконто;
- формирование печатной формы документа;
- использование общих модулей;
- разделение клиентской и серверной логики.
